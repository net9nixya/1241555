# Counter Faceit — Telegram Mini App

Next.js Mini App для профиля Counter Faceit с полноценной нижней навигацией и анимированным дизайном. Интерфейс рассчитан на открытие внутри Telegram и использует SVG-иконки `lucide-react`.

## Что уже есть
- минималистичный тёмный UI с розово-белым переливающимся заголовком;
- анимированное ELO-кольцо вокруг аватара, отражающее прогресс до следующего уровня;
- нижняя навигация с 5 вкладками: **Топ · Задания · Играть · Магазин · Профиль**, с плавным переключением и активным индикатором;
- **Топ** — три таблицы лидеров (по Эло / КД / победам), в том же формате, что и в самом боте (медали за 1-3 место);
- **Магазин** — карточки товаров VIP и Разбан с ценами в рублях/звёздах, как в боте (заглушка, кнопка "Купить" пока не подключена);
- **Задания** — список квестов с прогресс-барами и наградой в золоте (заглушка);
- **Играть** — заглушка под будущий поиск матча;
- профиль: ник, Game ID, ELO, уровень, бейджи VIP / Developer / Admin / Фембой;
- Win/Loss, Winrate, W/L Ratio, K/A/D, K/D, серии побед, Trust Factor, медали, последние матчи;
- плавное появление секций при загрузке (staggered reveal), уважает `prefers-reduced-motion`;
- Telegram Mini App `initData` передаётся на API;
- Vercel/Next.js API proxy;
- demo-профиль, чтобы приложение запускалось сразу после деплоя.

## Структура вкладок
Компоненты вкладок лежат в `app/components/`: `ProfileScreen.tsx`, `TopScreen.tsx`, `QuestsScreen.tsx`, `ShopScreen.tsx`, `PlayScreen.tsx`, `TabBar.tsx`. Данные для Топа и Магазина — в `app/lib/demo.ts` (`topBoards`, `shopItems`). Когда подключишь реального бота — замени эти константы на fetch к своему API, аналогично тому, как уже сделано в `app/api/profile/route.ts`.

## Аватар
Файл лежит в `public/avatar3.jpg`, подключается через `avatarUrl` в `app/lib/demo.ts`. Чтобы заменить — положи новый файл в `public/` и поменяй путь.

## Быстрый деплой
1. Распакуй папку и залей её в GitHub.
2. Импортируй репозиторий в Vercel.
3. Framework: Next.js (определится автоматически).
4. В Environment Variables добавь значения из `.env.example`.
5. Redeploy.

## Подключение реального бэкенда (уже готово)
Мини-апп умеет стучаться к реальным данным бота через `COUNTER_FACEIT_API_URL` — базовый адрес API, который читает те же SQLite-базы, что и сам бот:

- `GET {URL}/profile` — профиль игрока, открывшего мини-апп (по Telegram initData)
- `GET {URL}/profile/{nickname}` — профиль любого игрока по нику (для клика по строке в топе)
- `GET {URL}/top?board=elo|kd|wins` — таблица лидеров

Код этого API-сервера (`webapp_api.py`, на FastAPI, использует твой существующий `database.py`/`config.py`) лежит в папке `bot-webapp-api/` рядом с архивом мини-аппа — это отдельный файл, который нужно положить **на сервер с ботом** (не в Vercel!) и запустить рядом с `main.py`. Подробная инструкция для serv00 — в `bot-webapp-api/DEPLOY_SERV00.md`.

Пока `COUNTER_FACEIT_API_URL` не задан в Vercel — мини-апп показывает demo-данные, это нормально и ничего не ломает.

## ВАЖНО: подключение реальной БД (общая схема)
Vercel не должен напрямую читать SQLite-файл бота. Реальная схема должна быть:

Telegram Mini App → Vercel `/api/profile` → API Counter Faceit → `database.py` → БД

Vercel передаёт заголовок `X-Telegram-Init-Data`. Твой backend должен проверить Telegram WebApp `initData`, получить `telegram_id`, выбрать активного Faceit-пользователя и вернуть JSON формата из `app/lib/types.ts`.

Если `COUNTER_FACEIT_API_URL` не задан, приложение показывает demo-профиль — это специально, чтобы деплой можно было проверить сразу.
